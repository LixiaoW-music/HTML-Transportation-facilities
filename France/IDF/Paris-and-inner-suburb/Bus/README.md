# Bus in Paris and its inner suburbs
This directory contains my HTML reproductions of various components found on buses in Paris and the inner suburbs, including:
- destination signs (*girouettes* in French),
- side signs (*bandeaux* in French),
- stop and station name displays,
- and other passenger-information elements.

## File naming convention
Files are generally named according to the following convention:
`{document_type}_Bus{line_number}_{optional:AI_used}.html`
where:
document_type : "gir"=direction sign, "band"=side sign, "sta"=station name (additional document types may be added).
